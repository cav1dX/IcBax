# İçBax

Free bottled water advertising platform for businesses
in Azerbaijan.

## About

İçBax connects advertisers with consumers through
advertising placed on bottled water packaging.

## Features

- Responsive website
- Advertising packages
- WhatsApp integration
- Mobile-first design
- Modern UI
- Business-focused landing page

## Tech Stack

HTML
CSS
JavaScript
